Continuum for Google Antigravity: setup guide (Mac)

Continuum gives Antigravity a memory. Your notes live in a folder on your Mac. Antigravity reads the right note when you bring up its topic, asks you before it deletes or moves a note, and keeps a short record of every conversation.

On a Mac the setup file is started from the Terminal app, and this guide shows every step of that. You type two letters, answer a few questions, and then make a few clicks in Antigravity.

You need:

  • A Mac. Continuum was tested on macOS 14 (Intel). Node.js, the program Continuum runs on, asks for macOS 13.5 or later. Continuum has not been tested on a Mac with an Apple chip, or on macOS 15 or later.
  • The Antigravity app, on this Mac and signed in. This guide is for the app named Antigravity. Continuum has not been tested in the Antigravity IDE or in Antigravity's command line.
  • The Continuum zip file.
  • About 15 minutes.

Part 1. Get Node.js

Node.js is a free program Continuum runs on. If it is already on your Mac, go on to Part 2. If you are not sure, go on to Part 2 as well: the setup window tells you when Node.js is missing, and you can come back here.

  1. In your browser, open nodejs.org/en/download.
  2. The top of that page shows commands. You do not need them. Scroll down to the line Or get a prebuilt Node.js for macOS.
  3. Click the green button named macOS Installer (.pkg). A file lands in your Downloads folder. Its name starts with node-v and ends in .pkg.
  4. Open that file. A window opens that lists its pages: Introduction, Licence, Destination Select, Installation Type, Installation and Summary.
  5. Click Continue, then Continue again, then Agree, then Install.
  6. Your Mac asks for your Mac password. The box says Installer is trying to install new software. Type your Mac password there and click Install Software.
  7. Wait for the words The installation was completed successfully. Then click Close.
  8. Your Mac asks whether to move the installer to the Bin. Click Keep or Move to Bin. Either one is fine.

Part 2. Unzip the Continuum folder

  1. Find the Continuum zip file in your Downloads folder.
  2. Double-click it there. Your Mac unpacks it into a folder named Continuum, next to the zip file.
  3. Open the Continuum folder. Inside are files for Windows, with names that end in .cmd, files for the Mac, with names that end in .command, and the guides. On a Mac, use the files that end in .command.

Keep this folder, and leave its window open for Part 3. It holds the setup file and the two files for checking and removing Continuum.

Part 3. Start the setup file from Terminal

A double-click on the setup file does not work on a Mac when the zip file came from the internet. Your Mac shows a box that says "Continuum Setup for Antigravity.command" cannot be opened because it is from an unidentified developer, with one button, OK. That is the Mac's rule for files from the internet whose maker has not paid Apple to sign them. If you see that box, click OK.

The way that works is to start the file from the Terminal app. Terminal is an app on your Mac with a window you type into. No setting on your Mac is changed by this.

  1. Open Terminal: open Finder, then Applications, then Utilities, then Terminal.
    • Another way: open Launchpad, type Terminal and open it.
  2. Click in the Terminal window. Type the two letters sh and then one space. Do not press Return yet.
  3. Drag the file Continuum Setup for Antigravity.command from the Finder window into the Terminal window and let go. Its full name appears after sh.
  4. Press Return. The Terminal window now shows a few questions.

If the window says "Continuum needs Node.js": do Part 1, then do steps 2 to 4 here again.

Part 4. Answer the questions

Type your answer and press Return. When a suggestion is shown in [brackets], pressing Return alone accepts it. The window calls this key Enter.

  1. What is your name? Type your first name. Press Return.
  2. Where should your notes folder live? Press Return to accept the suggestion: a new folder named Continuum in your home folder, kept on this Mac. The brackets show its full address. The setup also puts an item named Continuum Notes on your Desktop that opens your notes folder, so you can always find it.
    • To use another folder, type its address. The address may start with ~/, which stands for your home folder, for example ~/My Notes. You can also drag a folder from a Finder window into the Terminal window.
  3. What should this computer be called in your notes? Press Return to accept the suggestion.
  4. Your time zone looks like ... Is that right? Press Return if it is right.
  5. The window lists what will be set up, under Here is what will be set up:. One of its lines is Desktop shortcut: Continuum Notes. At Go ahead? press Return.

The window then says Done. Continuum is set up. Under that it names the program folder, the settings folder, your notes folder and the Desktop shortcut. The program folder is the folder continuum, inside plugins, inside config, inside .gemini, in your home folder. The settings folder is the folder antigravity inside .continuum in your home folder.

Then the window lists the three steps that are left. Those same steps are in Part 5. The last line says You can close this window now. You can leave the window open until Part 5 is done: its line Notes folder: shows the address of your notes folder.

Part 5. Three steps in Antigravity

On a Mac the menus of an app are in the bar at the very top of the screen, next to the apple.

  1. If Antigravity is open, quit it and open it again: in the bar at the very top of the screen click Antigravity, then click Quit Antigravity. Then open Antigravity again.
    • To open the app again, use Launchpad or the Applications folder.
  2. Make your notes folder a project: in the list on the left, next to the word Projects, click the small folder picture with a plus sign, then click New Project, then Add Folder. In the left list click Desktop, click Continuum Notes once, then click Open. Do not pick the folder named .continuum with a dot in front (that one only holds settings), and do not pick the Continuum folder in Downloads (that one is the program you unzipped). Then click Next. If your Mac then offers to install the command line developer tools, you can click Cancel: Continuum does not need them.
    • There is no Workspace menu on a Mac. The small folder picture shows the words Create New Project when the mouse rests on it. A click on it opens a small menu with New Project and SSH Host...
    • New Project opens a box named Create Project. It shows This Computer and Remote, and the buttons Add Folder and Skip. After a folder is added, it shows Next.
    • The folder window may open in Downloads. The folder named Continuum there is the program you unzipped, not your notes. Click Desktop in the left list. Continuum Notes shows there as a folder. The buttons at the bottom are Cancel and Open.
    • If you do not see Continuum Notes there, the setup window shows the address of your notes folder on the line Notes folder:. Go to that folder instead.
    • The Mac's box about the developer tools says The "git" command requires the command line developer tools. Would you like to install the tools now? Its buttons are Cancel and Install.
  3. The name of your notes folder is now above the message box. Type this and send it: What are my standing rules? If the answer lists rules from your notes, Continuum is working.

Part 6. Check it any time

Start the file Continuum Check for Antigravity.command from Terminal, the same way as the setup file in Part 3: type sh and one space, drag the file into the Terminal window, press Return. It changes nothing. It says Everything is in place, or it names what is missing and the one thing to do about it.

Using it day to day

  • Open Antigravity and start a conversation in your notes project. Your rules and start page are loaded for Antigravity at the start of every conversation.
  • Your notes are plain files in your notes folder. Double-click Continuum Notes on your Desktop to open it. You can open and edit the notes yourself.
  • When Antigravity is about to delete, move or rewrite a note with a command, it stops and asks you first. The question starts with Allow and shows a text that starts with [continuum]. Choose Yes, allow this time or No. A copy of the note is kept before anything changes, in the folder .backups inside your notes folder. It asks every time.
  • When a note grows too large, Antigravity tells you and offers to split it into smaller notes. Nothing is ever shortened or thrown away.
  • Antigravity is told to read the whole note, and the notes that note points to, before it answers. When your notes do not hold the answer, it is told to say so and tell you where it looked.
  • When Antigravity needs something from you, it asks one question at a time. That is one of your standing rules, in the note Working Agreements. You can change any of them.

Where your notes live

Continuum is built to keep your notes on your Mac initially. The suggested folder is in your home folder and not inside Documents. On a Mac, Documents is often kept in iCloud, and the Mac then asks a question of its own before an app may read it. If you want your notes somewhere else, you can move them. That is up to you.

To move your notes:

  1. Quit Antigravity: in the bar at the very top of the screen click Antigravity, then click Quit Antigravity.
  2. Move your Continuum notes folder to the new place, the way you would move any folder.
  3. Start Continuum Setup for Antigravity.command from Terminal again, the same way as in Part 3. At the question Where should your notes folder live? type the address of the folder in its new place, or drag the folder from a Finder window into the Terminal window. Then press Return. Answer the other questions the same way as the first time.
  4. Open Antigravity again and do step 2 of Part 5 again, so the project is the folder in its new place.

Continuum Notes on your Desktop then opens the folder in its new place. If you set up Continuum for a second app on this Mac and give it a different notes folder, Continuum Notes opens the newest one.

If something does not work

  • A box says the file "cannot be opened because it is from an unidentified developer". The file was double-clicked. Click OK, then start the file from Terminal, as in Part 3.
  • The window says "Continuum needs Node.js". Do Part 1, then start the file from Terminal again.
  • Your Mac offers to install the command line developer tools. Click Cancel. Continuum does not need them.
  • The answer does not mention your rules. Check that the name above the message box is the name of your notes folder. If the project was made from the Continuum folder in Downloads, do step 2 of Part 5 again and pick Continuum Notes on the Desktop. Then do step 1 of Part 5 again and ask again.
  • Still nothing. Start Continuum Check for Antigravity.command from Terminal and do what it says.
  • The setup window says "Something did not work". Nothing else was changed after that point. The window names a log file with the details. Send that file to whoever gave you Continuum.

Removing it

  1. Start the file Continuum Remove for Antigravity.command from Terminal, the same way as the setup file in Part 3. Use the file in the Continuum folder you unzipped.
  2. Type YES and press Return.
  3. If Antigravity is open, quit it and open it again.

This takes Continuum out of Antigravity. Your notes folder and everything in it stay where they are.
