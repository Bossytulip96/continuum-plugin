Continuum for Codex: setup guide (Mac)

Continuum gives Codex a memory. Your notes live in a folder on your Mac. Codex reads the right note when you bring up its topic, asks you before it deletes or moves a note, and keeps a short record of every session.

On a Mac the setup file is started from the Terminal app, and this guide shows every step of that. You type two letters, answer a few questions, and then make a few clicks in the ChatGPT app.

You need:

  • A Mac. Continuum was tested on macOS 14 (Intel). Node.js, the program Continuum runs on, asks for macOS 13.5 or later. Continuum has not been tested on a Mac with an Apple chip, or on macOS 15 or later.
  • The ChatGPT desktop app, on this Mac and signed in, with Codex in it.
  • The Continuum zip file.
  • About 20 minutes.

Part 1. Get Node.js

Node.js is a free program Continuum runs on. If it is already on your Mac, go on to Part 2. If you are not sure, go on to Part 2 as well: the setup window tells you when Node.js is missing, and you can come back here.

  1. In your browser, open nodejs.org/en/download.
  2. The top of that page shows commands. You do not need them. Scroll down to the line Or get a prebuilt Node.js for macOS.
  3. Click the green button named macOS Installer (.pkg). A file lands in your Downloads folder. Its name starts with node-v and ends in .pkg.
  4. Open that file. A window opens that lists its pages: Introduction, Licence, Destination Select, Installation Type, Installation and Summary.
  5. Click Continue, then Continue again, then Agree, then Install.
  6. Your Mac asks for your Mac password. The box says Installer is trying to install new software. Type your Mac password there and click Install Software.
  7. Wait for the words The installation was completed successfully. Then click Close.
  8. Your Mac asks whether to move the installer to the Bin. Click Keep or Move to Bin. Either one is fine.

Part 2. Unzip the Continuum folder

  1. Find the Continuum zip file in your Downloads folder.
  2. Double-click it there. Your Mac unpacks it into a folder named Continuum, next to the zip file.
  3. Open the Continuum folder. Inside are files for Windows, with names that end in .cmd, files for the Mac, with names that end in .command, and the guides. On a Mac, use the files that end in .command.

Keep this folder, and leave its window open for Part 3. It holds the setup file and the two files for checking and removing Continuum.

Part 3. Start the setup file from Terminal

A double-click on the setup file does not work on a Mac when the zip file came from the internet. Your Mac shows a box that says "Continuum Setup for Codex.command" cannot be opened because it is from an unidentified developer, with one button, OK. That is the Mac's rule for files from the internet whose maker has not paid Apple to sign them. If you see that box, click OK.

The way that works is to start the file from the Terminal app. Terminal is an app on your Mac with a window you type into. No setting on your Mac is changed by this.

  1. Open Terminal: open Finder, then Applications, then Utilities, then Terminal.
    • Another way: open Launchpad, type Terminal and open it.
  2. Click in the Terminal window. Type the two letters sh and then one space. Do not press Return yet.
  3. Drag the file Continuum Setup for Codex.command from the Finder window into the Terminal window and let go. Its full name appears after sh.
  4. Press Return. The Terminal window now shows a few questions.

If the window says "Continuum needs Node.js": do Part 1, then do steps 2 to 4 here again.

Part 4. Answer the questions

Type your answer and press Return. When a suggestion is shown in [brackets], pressing Return alone accepts it. The window calls this key Enter.

  1. What is your name? Type your first name. Press Return.
  2. Where should your notes folder live? Press Return to accept the suggestion: a new folder named Continuum in your home folder, kept on this Mac. The brackets show its full address. The setup also puts an item named Continuum Notes on your Desktop that opens your notes folder, so you can always find it.
    • To use another folder, type its address. The address may start with ~/, which stands for your home folder, for example ~/My Notes. You can also drag a folder from a Finder window into the Terminal window.
  3. What should this computer be called in your notes? Press Return to accept the suggestion.
  4. Your time zone looks like ... Is that right? Press Return if it is right.
  5. The window lists what will be set up, under Here is what will be set up:. One of its lines is Desktop shortcut: Continuum Notes. At Go ahead? press Return.

The window then says Done. Continuum is set up. Under that it names the program folder, the settings folder, your notes folder and the Desktop shortcut. The program folder is the folder continuum, inside plugins, inside .codex, in your home folder. The settings folder is the folder codex inside .continuum in your home folder.

Then the window lists the six steps that are left. Those same steps are in Part 5. The last line says You can close this window now. You can leave the window open until Part 5 is done: its line Notes folder: shows the address of your notes folder.

Part 5. Six steps in the ChatGPT app

On a Mac the menus of an app are in the bar at the very top of the screen, next to the apple.

  1. In the bar at the very top of the screen click ChatGPT, then Quit ChatGPT. Then open the app again. (The red button in the corner only closes the window, so use Quit ChatGPT.)
    • To open the app again, use Launchpad or the Applications folder.
  2. At the top left of the window, look at the word with the small arrow next to it. If it says ChatGPT, click it and pick Codex. If it already says Codex, go on to the next step.
  3. In the bar at the very top of the screen click File, then Open Folder. In the left list click Desktop, click Continuum Notes once, then click Open. Do not pick the folder named .continuum with a dot in front (that one only holds settings), and do not pick the Continuum folder in Downloads (that one is the program you unzipped). If a box then asks Trust this folder?, check that it names your notes folder and click Trust folder.
    • Continuum Notes shows in the folder window as a folder. The buttons at the bottom are Cancel and Open.
    • If you do not see Continuum Notes there, the setup window shows the address of your notes folder on the line Notes folder:. Go to that folder instead.
    • The box Trust this folder? has the buttons Trust folder and Cancel.
  4. Open Settings: in the bar at the very top of the screen click ChatGPT, then Settings. (Another way: hold the Command key and press the comma key.) Type hooks in the search box and click Hooks. If that page does not show your notes folder, go back and open the other Hooks result. Click the row with your notes folder. If it says 6 need review, click Trust all. If it only says 6 hooks, they are already trusted from an earlier setup and there is nothing to click.
    • In the test on a Mac, the row showed 6 hooks and 6 need review. A click on the row showed the six hooks and the Trust all button. After Trust all, every switch was on.
  5. Go back to the chat screen. Above the message box you should see the name of your notes folder and the words This computer. In a small window you may see two small pictures there instead of the words: a folder and a laptop. If it does not say This computer, click it and pick This computer.
  6. Type this and send it: What are my standing rules? If the answer lists rules from your notes, Continuum is working.

Part 6. Check it any time

Start the file Continuum Check for Codex.command from Terminal, the same way as the setup file in Part 3: type sh and one space, drag the file into the Terminal window, press Return. It changes nothing. It says Everything is in place, or it names what is missing and the one thing to do about it.

Using it day to day

  • Open the ChatGPT app, switch to Codex, and open your notes folder the same way as in step 3 of Part 5.
  • Start a new chat there. Your rules and start page are loaded for Codex at the start of every chat.
  • Your notes are plain files in your notes folder. Double-click Continuum Notes on your Desktop to open it. You can open and edit the notes yourself.
  • When Codex is about to delete, move or rewrite a note, it stops and asks you yes or no first, in the chat. After your yes it goes on. A copy of the note is kept before anything changes, in the folder .backups inside your notes folder.
  • A yes to a delete covers deletes in your notes for one hour.
  • When a note grows too large, Codex tells you and offers to split it into smaller notes. Nothing is ever shortened or thrown away.
  • Codex is told to read the whole note, and the notes that note points to, before it answers. When your notes do not hold the answer, it is told to say so and tell you where it looked.
  • When Codex needs something from you, it asks one question at a time. That is one of your standing rules, in the note Working Agreements. You can change any of them.

One thing to know:

  • Continuum only works in chats that run on This computer, in the Codex screen, inside your notes folder. A chat that runs in the cloud does not load your notes.

Where your notes live

Continuum is built to keep your notes on your Mac initially. The suggested folder is in your home folder and not inside Documents. On a Mac, Documents is often kept in iCloud, and the Mac then asks a question of its own before an app may read it. If you want your notes somewhere else, you can move them. That is up to you.

To move your notes:

  1. In the bar at the very top of the screen click ChatGPT, then Quit ChatGPT.
  2. Move your Continuum notes folder to the new place, the way you would move any folder.
  3. Start Continuum Setup for Codex.command from Terminal again, the same way as in Part 3. At the question Where should your notes folder live? type the address of the folder in its new place, or drag the folder from a Finder window into the Terminal window. Then press Return. Answer the other questions the same way as the first time.
  4. Do the six steps in Part 5 again, so Codex opens the folder in its new place.

Continuum Notes on your Desktop then opens the folder in its new place. If you set up Continuum for a second app on this Mac and give it a different notes folder, Continuum Notes opens the newest one.

If something does not work

  • A box says the file "cannot be opened because it is from an unidentified developer". The file was double-clicked. Click OK, then start the file from Terminal, as in Part 3.
  • The window says "Continuum needs Node.js". Do Part 1, then start the file from Terminal again.
  • The answer does not mention your rules. Check three things: you are in the Codex screen, your notes folder is the folder you opened, and it says This computer above the message box. Then start a new chat and ask again.
  • Still nothing. Start Continuum Check for Codex.command from Terminal and do what it says. The most common miss is the Trust all click in step 4 of Part 5.
  • The setup window says "Something did not work". Nothing else was changed after that point. The window names a log file with the details. Send that file to whoever gave you Continuum.

Removing it

  1. Start the file Continuum Remove for Codex.command from Terminal, the same way as the setup file in Part 3.
  2. Type YES and press Return.

This takes Continuum out of Codex. Your notes folder and everything in it stay where they are.
