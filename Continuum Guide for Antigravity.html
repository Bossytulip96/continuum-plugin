Continuum for Google Antigravity: setup guide (Windows 11)

Continuum gives Antigravity a memory. Your notes live in a folder on your computer. Antigravity reads the right note when you bring up its topic, asks you before it deletes or moves a note, and keeps a short record of every conversation.

This guide has no commands to type. You double-click one file, answer a few questions, and then make a few clicks in Antigravity.

You need:

  • A Windows 11 computer. Continuum has not been tested on Windows 10, and this guide is for Windows. For a Mac, open Continuum Guide for Antigravity on a Mac instead.
  • The Antigravity app, installed and signed in. This guide is for the app named Antigravity. Continuum has not been tested in the Antigravity IDE or in Antigravity's command line.
  • The Continuum zip file.
  • About 10 minutes.

Part 1. Unzip the Continuum folder

  1. Find the Continuum zip file (usually in your Downloads folder).
  2. Right-click it and choose Properties. At the bottom of the small window that opens, look for the word Unblock. If it is there, tick the box next to it. Then click OK.
    • Windows marks a file that came from the internet. On some Windows 11 computers the setup file will not open while the zip file carries that mark. Unblock takes the mark off the zip file. It does not change a folder that was already unzipped.
    • Do this only for the Continuum zip file you meant to download.
    • If there is no Unblock, click OK and go on.
  3. Right-click the zip file again and choose Extract All...
  4. A small window shows where the folder will go. Leave it as it is and click Extract. A normal folder opens with the Continuum files in it.

Keep this folder. It holds the setup file and the two files for checking and removing Continuum.

Part 2. Run the setup file

  1. In that folder, double-click the file named Continuum Setup for Antigravity.
  2. If Windows shows a warning before it opens, choose Run. If the warning is a blue box that says "Windows protected your PC", click More info, then Run anyway.
    • If the box says Smart App Control blocked a file that may be unsafe, it has no Run button. Click Okay and go to If something does not work near the end of this guide.
  3. A black window opens with a few questions.

If the window says "Continuum needs Node.js": Node.js is a free program Continuum runs on. Get it from its own website, not from the Microsoft Store.

  1. Open nodejs.org in your browser.
  2. Click the button Get Node.js.
  3. Click Windows Installer (.msi) and wait for the download.
  4. Open the downloaded file. Click Next on every screen, then Install, then Finish.
  5. Double-click Continuum Setup for Antigravity again.

Part 3. Answer the questions

Type your answer and press Enter. When a suggestion is shown in [brackets], pressing Enter alone accepts it.

  1. What is your name? Type your first name. Press Enter.
  2. Where should your notes folder live? Press Enter to accept the suggestion: a new folder named Continuum, kept on this computer. The setup also puts a shortcut named Continuum Notes on your Desktop, so you can always find it.
  3. What should this computer be called in your notes? Press Enter to accept the suggestion.
  4. Your time zone looks like ... Is that right? Press Enter if it is right.
  5. Go ahead? Press Enter.

The window then says Done. Continuum is set up and lists the steps that are left. Those same steps are in Part 4. Press any key to close the window.

Part 4. Three steps in Antigravity

  1. If Antigravity is open, close it and open it again: at the top of the Antigravity window click Window, then click Close. Then open Antigravity again.
  2. Make your notes folder a project: click Workspace, then Create Project, then Add Folder. In the left list click Desktop, double-click Continuum Notes, then click Select Folder. Then click Next.
    • If you do not see Continuum Notes there, the black setup window shows the address of your notes folder on the line Notes folder:. Go to that folder instead.
    • Do not pick the folder named .continuum with a dot in front. That one only holds settings. Your notes folder has no dot.
  3. A new conversation opens, with the name of your notes folder above the message box. Type this and send it: What are my standing rules? If the answer lists rules from your notes, Continuum is working.

To see Continuum listed: click Customizations in the list on the left, then Installed. Continuum is under Plugins.

Part 5. Check it any time

Double-click Continuum Check for Antigravity in the Continuum folder. It changes nothing. It says Everything is in place, or it names what is missing and the one thing to do about it.

Using it day to day

  • Open Antigravity. Under Projects in the list on the left, point at your notes folder and click the + next to it to start a conversation there. Your rules and start page are loaded for Antigravity at the start of every conversation.
  • Your notes are plain files in your notes folder. Double-click Continuum Notes on your Desktop to open it. You can open and edit the notes yourself.
  • When Antigravity is about to delete, move or rewrite a note with a command, it stops and asks you first. The question shows a line that starts with [continuum]. Choose Yes, allow this time or No. A copy of the note is kept before anything changes. It asks every time.
  • Continuum also runs in conversations that are not in your notes project. There Antigravity has a question of its own: before it opens or changes a file in your notes folder, it asks Allow read access to this path? or Allow write access to this path? Check that the address shown is in your notes folder, then choose Yes, allow this time. In your notes project it does not ask.
  • When a note grows too large, Antigravity tells you and offers to split it into smaller notes. Nothing is ever shortened or thrown away.
  • Antigravity is told to read the whole note, and the notes that note points to, before it answers. When your notes do not hold the answer, it is told to say so and tell you where it looked.
  • When Antigravity needs something from you, it asks one question at a time. That is one of your standing rules, in the note Working Agreements. You can change any of them.

Where your notes live

Continuum is built to keep your notes on your computer initially. If you have a drive or somewhere else to store them, such as Google Drive or OneDrive, you can move them there. That is up to you.

To move your notes:

  1. Close Antigravity: click Window, then Close.
  2. Move your Continuum notes folder to the new place, the way you would move any folder.
  3. Double-click Continuum Setup for Antigravity again. At the question Where should your notes folder live? type the address of the folder in its new place and press Enter. Answer the other questions the same way as the first time.
  4. Open Antigravity again and do step 2 of Part 4 again, so the project is the folder in its new place.

If something does not work

  • A box says "Smart App Control blocked a file that may be unsafe". The unzipped files still carry the mark Windows puts on files from the internet. Click Okay. Delete the folder that Extract All made (keep the zip file). Then do Part 1 again and tick Unblock in step 2, and double-click the setup file again. If Windows still blocks it, stop and send the exact words in the box to whoever gave you Continuum. Leave Smart App Control on.
  • The answer does not mention your rules. Close Antigravity with Window, then Close, open it again, click New Conversation at the top of the list on the left and ask again.
  • A box asks "Allow read access to this path?" The conversation is not in your notes project. If the address shown is in your notes folder, choose Yes, allow this time.
  • Still nothing. Double-click Continuum Check for Antigravity and do what it says. Then click Customizations, then Installed, and look for Continuum under Plugins.
  • The setup window says "Something did not work". Nothing else was changed after that point. The window names a log file with the details. Send that file to whoever gave you Continuum.

Removing it

  1. Double-click Continuum Remove for Antigravity in the Continuum folder you unzipped.
  2. Type YES and press Enter.
  3. If Antigravity is open, close it and open it again.

This takes Continuum out of Antigravity. Your notes folder and everything in it stay where they are.
