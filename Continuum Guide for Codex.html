Continuum for Codex: setup guide (Windows)

Continuum gives Codex a memory. Your notes live in a folder on your computer. Codex reads the right note when you bring up its topic, asks you before it deletes or moves a note, and keeps a short record of every session.

This guide has no commands to type. You double-click one file, answer a few questions, and then make a few clicks in the ChatGPT app.

You need:

  • A Windows 10 or Windows 11 computer.
  • The ChatGPT desktop app, signed in, with Codex in it.
  • The Continuum zip file.
  • About 15 minutes.

Part 1. Unzip the Continuum folder

  1. Find the Continuum zip file (usually in your Downloads folder).
  2. Right-click it and choose Properties. At the bottom of the small window that opens, look for the word Unblock. If it is there, tick the box next to it. Then click OK.
    • Windows marks a file that came from the internet. On some Windows 11 computers the setup file will not open while the zip file carries that mark. Unblock takes the mark off the zip file. It does not change a folder that was already unzipped.
    • Do this only for the Continuum zip file you meant to download.
    • If there is no Unblock, click OK and go on.
  3. Right-click the zip file again and choose Extract All...
  4. A small window shows where the folder will go. Leave it as it is and click Extract. A normal folder opens with the Continuum files in it.

Keep this folder. It holds the setup file and the two files for checking and removing Continuum.

Part 2. Run the setup file

  1. In that folder, double-click the file named Continuum Setup for Codex.
  2. If Windows shows a warning before it opens, choose Run. If the warning is a blue box that says "Windows protected your PC", click More info, then Run anyway.
    • If the box says Smart App Control blocked a file that may be unsafe, it has no Run button. Click Okay and go to If something does not work near the end of this guide.
  3. A black window opens with a few questions.

If the window says "Continuum needs Node.js": Node.js is a free program Continuum runs on. Get it from its own website, not from the Microsoft Store.

  1. Open nodejs.org in your browser.
  2. Click the button Get Node.js.
  3. Click Windows Installer (.msi) and wait for the download.
  4. Open the downloaded file. Click Next on every screen, then Install, then Finish.
  5. Double-click Continuum Setup for Codex again.

Part 3. Answer the questions

Type your answer and press Enter. When a suggestion is shown in [brackets], pressing Enter alone accepts it.

  1. What is your name? Type your first name. Press Enter.
  2. Where should your notes folder live? Press Enter to accept the suggestion: a new folder named Continuum, kept on this computer. The setup also puts a shortcut named Continuum Notes on your Desktop, so you can always find it.
  3. What should this computer be called in your notes? Press Enter to accept the suggestion.
  4. Your time zone looks like ... Is that right? Press Enter if it is right.
  5. Go ahead? Press Enter.

The window then says Done. Continuum is set up and lists the steps that are left. Those same steps are in Part 4. Press any key to close the window.

Part 4. Six steps in the ChatGPT app

  1. In the ChatGPT app click File, then Quit ChatGPT. Then open the app again. (The X in the corner only hides the app, so use Quit.)
  2. At the top left, look at the word with the small arrow next to it. If it says ChatGPT, click it and pick Codex. If it already says Codex, go on to the next step.
  3. Click File, then Open Folder. In the left list click Desktop, double-click Continuum Notes, then click Select Folder.
    • If you do not see Continuum Notes there, the black setup window shows the address of your notes folder on the line Notes folder:. Go to that folder instead.
    • Do not pick the folder named .continuum with a dot in front. That one only holds settings. Your notes folder has no dot.
  4. Hold Ctrl and press the comma key to open Settings. Type hooks in the search box and click Hooks. Click the row with your notes folder. If it says 6 need review, click Trust all.
    • If the search shows two results named Hooks and the first page does not show your notes folder, go back and open the other one.
    • Another way into Settings: click the round button with your initials at the bottom left, then Settings.
    • If the row only says 6 hooks, they are already trusted from an earlier setup and there is nothing to click.
  5. Go back to the chat screen. Above the message box you should see the name of your notes folder and the words This computer. In a small window you may see two small pictures there instead of the words: a folder and a laptop. If it does not say This computer, click it and pick This computer.
  6. Type this and send it: What are my standing rules? If the answer lists rules from your notes, Continuum is working.

Part 5. Check it any time

Double-click Continuum Check for Codex in the Continuum folder. It changes nothing. It says Everything is in place, or it names what is missing and the one thing to do about it.

Using it day to day

  • Open the ChatGPT app, switch to Codex, and click your notes folder under Projects.
  • Start a new chat there. Your rules and start page are loaded for Codex at the start of every chat.
  • Your notes are plain files in your notes folder. Double-click Continuum Notes on your Desktop to open it. You can open and edit the notes yourself.
  • When Codex is about to delete, move or rewrite a note, it stops and asks you yes or no first. A copy of the note is kept before anything changes.
  • A yes to a delete covers deletes in your notes for one hour.
  • When a note grows too large, Codex tells you and offers to split it into smaller notes. Nothing is ever shortened or thrown away.
  • Codex is told to read the whole note, and the notes that note points to, before it answers. When your notes do not hold the answer, it is told to say so and tell you where it looked.
  • When Codex needs something from you, it asks one question at a time. That is one of your standing rules, in the note Working Agreements. You can change any of them.

One thing to know:

  • Continuum only works in chats that run on This computer, in the Codex screen, inside your notes folder. A chat that runs in the cloud does not load your notes.

Where your notes live

Continuum is built to keep your notes on your computer initially. If you have a drive or somewhere else to store them, such as Google Drive or OneDrive, you can move them there. That is up to you.

To move your notes:

  1. In the ChatGPT app click File, then Quit ChatGPT.
  2. Move your Continuum notes folder to the new place, the way you would move any folder.
  3. Double-click Continuum Setup for Codex again. At the question Where should your notes folder live? type the address of the folder in its new place and press Enter. Answer the other questions the same way as the first time.
  4. Do the six steps in Part 4 again, so Codex opens the folder in its new place.

On a cloud or network drive Codex shows a warning that it may not work safely there.

If something does not work

  • A box says "Smart App Control blocked a file that may be unsafe". The unzipped files still carry the mark Windows puts on files from the internet. Click Okay. Delete the folder that Extract All made (keep the zip file). Then do Part 1 again and tick Unblock in step 2, and double-click the setup file again. If Windows still blocks it, stop and send the exact words in the box to whoever gave you Continuum. Leave Smart App Control on.
  • The answer does not mention your rules. Check three things: you are in the Codex screen, your notes folder is the project, and it says This computer above the message box. Then start a new chat and ask again.
  • Still nothing. Double-click Continuum Check for Codex and do what it says. The most common miss is the Trust all click in step 4.
  • The setup window says "Something did not work". Nothing else was changed after that point. The window names a log file with the details. Send that file to whoever gave you Continuum.

Removing it

  1. Double-click Continuum Remove for Codex in the Continuum folder.
  2. Type YES and press Enter.

This takes Continuum out of Codex. Your notes folder and everything in it stay where they are.
