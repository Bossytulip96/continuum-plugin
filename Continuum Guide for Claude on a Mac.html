Continuum for the Claude app: setup guide (Mac)

Continuum gives Claude a memory. Your notes live in a folder on your Mac, and Claude reads the right note when you bring up its topic.

Claude asks you before it deletes or moves a note, and it keeps a short record of every session.

On a Mac the setup file is started from the Terminal app, and this guide shows every step of that. You type two letters, answer a few questions, and then make a few clicks in the Claude app.

You need:

  • A Mac. Continuum was tested on macOS 14 (Intel). Node.js, the program Continuum runs on, asks for macOS 13.5 or later. Continuum has not been tested on a Mac with an Apple chip, or on macOS 15 or later.
  • The Claude desktop app, on this Mac and signed in, with a paid plan and its Code tab.
  • The Continuum zip file.
  • About 20 minutes.

Part 1. Get Node.js

Node.js is a free program Continuum runs on. If it is already on your Mac, go on to Part 2. If you are not sure, go on to Part 2 as well: the setup window tells you when Node.js is missing, and you can come back here.

  1. In your browser, open nodejs.org/en/download.
  2. The top of that page shows commands. You do not need them. Scroll down to the line Or get a prebuilt Node.js for macOS.
  3. Click the green button named macOS Installer (.pkg). A file lands in your Downloads folder. Its name starts with node-v and ends in .pkg.
  4. Open that file. A window opens that lists its pages: Introduction, Licence, Destination Select, Installation Type, Installation and Summary.
  5. Click Continue, then Continue again, then Agree, then Install.
  6. Your Mac asks for your Mac password. The box says Installer is trying to install new software. Type your Mac password there and click Install Software.
  7. Wait for the words The installation was completed successfully. Then click Close.
  8. Your Mac asks whether to move the installer to the Bin. Click Keep or Move to Bin. Either one is fine.

Part 2. Unzip the Continuum folder

  1. Find the Continuum zip file in your Downloads folder.
  2. Double-click it there. Your Mac unpacks it into a folder named Continuum, next to the zip file.
  3. Open the Continuum folder. Inside are files for Windows, with names that end in .cmd, files for the Mac, with names that end in .command, and the guides. On a Mac, use the files that end in .command.

Keep this folder, and leave its window open for Part 3. It holds the setup file and the two files for checking and removing Continuum.

Part 3. Start the setup file from Terminal

A double-click on the setup file does not work on a Mac when the zip file came from the internet. Your Mac shows a box that says "Continuum Setup for Claude.command" cannot be opened because it is from an unidentified developer, with one button, OK. That is the Mac's rule for files from the internet whose maker has not paid Apple to sign them. If you see that box, click OK.

The way that works is to start the file from the Terminal app. Terminal is an app on your Mac with a window you type into. No setting on your Mac is changed by this.

  1. Open Terminal: open Finder, then Applications, then Utilities, then Terminal.
    • Another way: open Launchpad, type Terminal and open it.
  2. Click in the Terminal window. Type the two letters sh and then one space. Do not press Return yet.
  3. Drag the file Continuum Setup for Claude.command from the Finder window into the Terminal window and let go. Its full name appears after sh.
  4. Press Return. The Terminal window now shows a few questions.

If the window says "Continuum needs Node.js": do Part 1, then do steps 2 to 4 here again.

Part 4. Answer the questions

Type your answer and press Return. When a suggestion is shown in [brackets], pressing Return alone accepts it. The window calls this key Enter.

  1. What is your name? Type your first name. Press Return.
  2. Where should your notes folder live? Press Return to accept the suggestion: a new folder named Continuum in your home folder, kept on this Mac. The brackets show its full address. The setup also puts an item named Continuum Notes on your Desktop that opens your notes folder, so you can always find it.
    • To use another folder, type its address. The address may start with ~/, which stands for your home folder, for example ~/My Notes. You can also drag a folder from a Finder window into the Terminal window.
  3. What should this computer be called in your notes? Press Return to accept the suggestion.
  4. Your time zone looks like ... Is that right? Press Return if it is right.
  5. The window lists what will be set up, under Here is what will be set up:. One of its lines is Desktop shortcut: Continuum Notes. At Go ahead? press Return.

The setup also changes one file of Claude's own: its settings file. It adds Continuum's lines there, so Claude runs Continuum, and it lets Claude read your notes folder. A copy of the file as it was is kept first. Nothing else in that file changes.

The window then says Done. Continuum is set up. Under that it names the program folder, the settings folder, your notes folder, the Desktop shortcut, Claude's settings file and the copy of that file. The program folder is the folder program inside the folder .continuum in your home folder, and .continuum itself is the settings folder.

Then the window lists the four steps that are left. Those same steps are in Part 5. The last line says You can close this window now. You can leave the window open until Part 5 is done: its line Notes folder: shows the address of your notes folder.

Part 5. Four steps in the Claude app

On a Mac the menus of an app are in the bar at the very top of the screen, next to the apple.

  1. Quit the Claude app completely, then open it again: in the bar at the very top of the screen click Claude, then click Quit Claude. (The red button in the corner only closes the window, so use Quit Claude.)
    • To open the app again, use Launchpad or the Applications folder.
  2. At the top left of the Claude window there are two small pictures side by side. Click the one that looks like </> . That one is Code.
  3. Click + New at the top of the list on the left. Under the message box it should say This computer; if it says something else, click it and pick This computer. Next to it click Choose folder (if you used a folder before, the button shows that folder's name), then click Open folder... In the left list click Desktop, click Continuum Notes once, then click Open. Do not pick the folder named .continuum with a dot in front (that one only holds settings), and do not pick the Continuum folder in Downloads (that one is the program you unzipped). If a box then asks Trust this workspace?, check that it names your notes folder and click Trust workspace.
    • The folder window is titled Select folder. Continuum Notes shows there as a folder. The buttons at the bottom are Cancel and Open.
    • If you do not see Continuum Notes there, the setup window shows the address of your notes folder on the line Notes folder:. Go to that folder instead.
    • The box Trust this workspace? has the buttons Cancel and Trust workspace.
  4. Type this and send it: What are my standing rules? If the answer lists rules from your notes, Continuum is working.
    • A new notes folder starts with 12 standing rules, so the first answer lists those 12.

Part 6. Check it any time

Start the file Continuum Check for Claude.command from Terminal, the same way as the setup file in Part 3: type sh and one space, drag the file into the Terminal window, press Return. It changes nothing. It says Everything is in place, or it names what is missing and the one thing to do about it.

Using it day to day

  • Open the Claude app, click the </> picture at the top left, click + New, and pick your notes folder the same way as in step 3 of Part 5.
  • Your rules and start page are loaded for Claude at the start of every session.
  • Your notes are plain files in your notes folder. Double-click Continuum Notes on your Desktop to open it. You can open and edit the notes yourself.
  • When Claude is about to delete or move a note, it stops and asks you first. For a delete, a box asks Allow Claude to run this command? and shows a line that starts with [continuum]. Click Allow once or Deny. A copy of the note is kept first, in the folder .backups inside your notes folder.
  • When Claude rewrites a note, a copy of the note as it was is kept first.
  • When a note grows too large, Claude tells you and offers to split it into smaller notes. Nothing is ever shortened or thrown away.
  • Claude is told to read the whole note, and the notes that note points to, before it answers. When your notes do not hold the answer, it is told to say so and tell you where it looked.
  • When Claude needs something from you, it asks one question at a time. That is one of your standing rules, in the note Working Agreements. You can change any of them.

Where your notes live

Continuum is built to keep your notes on your Mac initially. The suggested folder is in your home folder and not inside Documents. On a Mac, Documents is often kept in iCloud, and the Mac then asks a question of its own before an app may read it. If you want your notes somewhere else, you can move them. That is up to you.

To move your notes:

  1. Quit the Claude app completely, the same way as in step 1 of Part 5.
  2. Move your Continuum notes folder to the new place, the way you would move any folder.
  3. Start Continuum Setup for Claude.command from Terminal again, the same way as in Part 3. At the question Where should your notes folder live? type the address of the folder in its new place, or drag the folder from a Finder window into the Terminal window. Then press Return. Answer the other questions the same way as the first time.
  4. Do the four steps in Part 5 again, so Claude opens the folder in its new place.

Continuum Notes on your Desktop then opens the folder in its new place. If you set up Continuum for a second app on this Mac and give it a different notes folder, Continuum Notes opens the newest one.

If something does not work

  • A box says the file "cannot be opened because it is from an unidentified developer". The file was double-clicked. Click OK, then start the file from Terminal, as in Part 3.
  • The window says "Continuum needs Node.js". Do Part 1, then start the file from Terminal again.
  • The answer does not mention your rules. Check two things: you are in Code (the </> picture), and the name of your notes folder shows under the message box. Then click + New and ask again.
  • Still nothing. Do step 1 of Part 5 again, so the app is quit completely and opened again. Then start Continuum Check for Claude.command from Terminal and do what it says.
  • The setup window says "Something did not work". Nothing else was changed after that point. The window names a log file with the details. Send that file to whoever gave you Continuum.

Removing it

  1. Start the file Continuum Remove for Claude.command from Terminal, the same way as the setup file in Part 3.
  2. Type YES and press Return.

This takes Continuum's lines out of Claude's settings file, so Claude no longer runs Continuum. Everything else in that file stays. Your notes folder and everything in it stay where they are.
